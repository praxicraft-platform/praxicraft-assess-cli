# Contributing to Praxicraft Assess CLI

Thanks for helping improve Praxicraft Assess open source.

Please read our [Code of Conduct](./CODE_OF_CONDUCT.md). Report unacceptable behavior to [support@praxicraft.com](mailto:support@praxicraft.com).

## How to contribute

1. Fork the repository and create a feature branch.
2. Make focused changes with clear commit messages.
3. Add or update tests when behavior changes.
4. Open a pull request describing **why** the change is needed.

## Development setup

```bash
bun install
bun run src/index.ts
bun run build
```

Requires [Bun](https://bun.sh) ≥ 1.1. Interactive TUI uses OpenTUI.

## Pull requests

- Keep PRs small and focused.
- Link related issues when applicable.
- Ensure CI passes before requesting review.
